Day 2 – AWS S3 & SageMaker

Learned how to use AWS S3 for storing ML data and model files and Amazon SageMaker for machine learning.

What I Did
Created an S3 bucket and uploaded the customer dataset.
Connected SageMaker Studio with S3 and loaded the data using Boto3.
Trained a Random Forest Classifier using the dataset.
Split the data into training and testing sets.
Tested the model and checked its accuracy.
Saved the trained model as model.joblib.
Uploaded the trained model back to S3.

Tools: AWS S3, Amazon SageMaker, Python, Boto3, Pandas, Scikit-learn
