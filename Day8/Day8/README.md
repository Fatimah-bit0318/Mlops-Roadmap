# Day 8 — SageMaker House-Price Pipeline

## Goal
Prepare an MLOps workflow that trains a house-price model with SageMaker's managed XGBoost container, evaluates it with RMSE, and conditionally registers the model.

## Files
- `pipeline-expanded.py` — SageMaker pipeline definition generator.
- `pipeline-expanded-definition.json` — placeholder file; regenerate in the SageMaker environment.
- `evaluate_model.py` — evaluation script for the trained XGBoost model.
- `train.csv` — training data, target column first, no header.
- `validation.csv` — validation data, target column first, no header.
- `test.csv` — held-out evaluation data, target column first, no header.

## Important dataset note
The three CSVs in this download are **sample placeholder data created for the project folder**. They are not recovered copies of your original SageMaker CSVs. Replace them with your actual data before running the pipeline.

## Technologies
- AWS SageMaker SDK
- SageMaker Pipelines
- Amazon S3
- XGBoost
- Python

## Workflow
1. Train XGBoost using `train.csv`.
2. Provide `validation.csv` as the validation channel.
3. Evaluate the trained model using `test.csv`.
4. Calculate RMSE and save `evaluation.json`.
5. If RMSE is at most 2,000,000, register the model with `PendingManualApproval`.

## Current status
The pipeline source code is prepared for the SageMaker SDK environment. The pipeline definition JSON in this bundle is only a placeholder and must be regenerated by running `pipeline-expanded.py` in the configured SageMaker JupyterLab environment. No AWS training or processing jobs have been run by this bundle.

## Before running in AWS
1. Replace the sample CSVs with your actual datasets.
2. Confirm the bucket, role ARN, region, and S3 script path in `pipeline-expanded.py`.
3. Upload `evaluate_model.py` to `s3://day04/day8/code/evaluate_model.py`.
4. Upload `train.csv`, `validation.csv`, and `test.csv` to their matching S3 paths.
5. Review AWS pricing and approve execution before starting jobs.
