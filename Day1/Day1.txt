## ML Workflow

Dataset → Features & Target → Train/Test Split → Model Training → Prediction → Evaluation

## Key Concepts

* `X` → Input features
* `y` → Target/label
* `fit()` → Trains the model
* `predict()` → Generates predictions
* `accuracy_score()` → Evaluates predictions
